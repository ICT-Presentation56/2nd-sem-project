# ToDo List Application

## Overview
This is a ToDo List Application developed as a 2nd Semester Software Engineering project. The application helps users manage daily tasks by adding, updating, deleting, and tracking their tasks.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- User-friendly interface

## Technologies Used
- C#
- Windows Forms (.NET)
- SQL Server
- Visual Studio
- Voice reminder for tasks
- System.Speech

## Database
The project uses SQL Server to store and manage task information.

## How to Run
1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Restore the database if required.
4. Update the SQL Server connection string.
5. Run the project.
